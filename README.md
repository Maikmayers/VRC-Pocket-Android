### Installation auf Android

1. Öffne den APK-Download oder die Release-Seite im Browser deines Android-Geräts.
2. Lade **VRC-Pocket-Android-Alpha-0.12-1.apk** herunter. Für die Installation benötigst du die APK; ein Quellcode-ZIP ist kein Android-Installationspaket.
3. Öffne die heruntergeladene Datei über die Download-Anzeige oder deinen Dateimanager.
4. Falls Android danach fragt, erlaube dem verwendeten Browser oder Dateimanager, Apps aus dieser Quelle zu installieren. Die Einstellung heißt je nach Gerät beispielsweise **Unbekannte Apps installieren** oder **Dieser Quelle vertrauen**. Erteile diese Erlaubnis nur für eine Quelle, der du vertraust.
5. Bestätige die Installation, öffne **VRC Pocket** und folge den Hinweisen in der App.
6. Falls Android eine Benachrichtigungsberechtigung abfragt, erlaube sie, wenn du Benachrichtigungen erhalten möchtest.

Die Bezeichnungen und Dialoge können je nach Android-Version und Hersteller abweichen. Nach der Installation kannst du die Erlaubnis zum Installieren unbekannter Apps für den Browser oder Dateimanager wieder deaktivieren.

### Hilfe und Fehler melden

Bitte prüfe zunächst die [vorhandenen Issues](https://github.com/Maikmayers/VRC-Pocket-Android/issues), damit eine Meldung nicht doppelt angelegt wird. Ist dein Problem noch nicht aufgeführt, [erstelle ein neues Issue](https://github.com/Maikmayers/VRC-Pocket-Android/issues/new). Dafür benötigst du ein GitHub-Konto.

Eine hilfreiche Fehlermeldung enthält:

- Einen kurzen, eindeutigen Titel
- App-Version, zum Beispiel **Alpha 0.12-1**
- Gerätemodell und Android-Version
- Schritte, mit denen sich der Fehler nachvollziehen lässt
- Erwartetes und tatsächlich beobachtetes Verhalten
- Falls hilfreich: einen Screenshot oder den genauen Fehlertext

Issues sind öffentlich. Veröffentliche keine Passwörter, Anmeldecodes, Sitzungstokens oder andere vertrauliche Daten. Entferne solche Angaben auch aus Screenshots und Protokollen.

Auch Verbesserungsvorschläge kannst du über GitHub Issues einreichen. Beschreibe dabei, was du erreichen möchtest und wie die Änderung helfen würde.

## English

### Overview

VRC Pocket lets you follow friend activity, receive notifications, and use additional VRChat-related features on Android. The app is available in German and English.

**Alpha release:** VRC Pocket is at an early stage of development. Bugs, crashes, or incomplete features may occur. Feedback helps improve the app.

### Features

The published [release notes](https://github.com/Maikmayers/VRC-Pocket-Android/releases/tag/VRC) describe these features:

- Friend activity and related notifications
- Boops
- World search
- Favorites
- Event calendar
- German and English interface

### Install on Android

1. Open the APK download or release page in your Android device's browser.
2. Download **VRC-Pocket-Android-Alpha-0.12-1.apk**. Installation requires the APK; a source code ZIP is not an Android installation package.
3. Open the downloaded file from the download notification or your file manager.
4. If Android prompts you, allow the browser or file manager you are using to install apps from this source. Depending on your device, the setting may be called **Install unknown apps** or **Allow from this source**. Grant this permission only for a source you trust.
5. Confirm installation, open **VRC Pocket**, and follow the instructions in the app.
6. If Android requests notification permission, allow it if you want to receive notifications.

Labels and dialogs may differ by Android version and device manufacturer. After installation, you can turn off the browser's or file manager's permission to install unknown apps again.

### Get help and report issues

Please check [existing issues](https://github.com/Maikmayers/VRC-Pocket-Android/issues) first to avoid duplicates. If your problem has not been reported, [open a new issue](https://github.com/Maikmayers/VRC-Pocket-Android/issues/new). A GitHub account is required.

A useful bug report includes:

- A short, clear title
- App version, for example **Alpha 0.12-1**
- Device model and Android version
- Steps to reproduce the problem
- Expected behavior and what actually happened
- A screenshot or the exact error message, if helpful

Issues are public. Do not post passwords, sign-in codes, session tokens, or other confidential information. Remove these details from screenshots and logs as well.

You can also submit suggestions through GitHub Issues. Explain what you want to achieve and how the proposed change would help.
